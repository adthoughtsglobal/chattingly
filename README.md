## How chattingly Works?
Chattingly is a websocket based progressive web application which makes it possible for you to quickly send messages to anyone you like! But how does this work?

Chattingly uses JSON to pad the messages and add more data, complex functions are used for the safty on this method to make sure that no one abuses it to take control over your device. The arranged pages and exclsive features are enteirely invented, yeah, it was indeed hard.

Using JSON, strings are covered with double quotes ("), which if there in a message, completely bugs out the messages resulting in message removal.

The websocket server is a virtual server, runned through Replit[^1], which allows us to constantly modify it without breaking it.
